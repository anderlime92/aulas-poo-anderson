# Exemplos de POO

Neste repositório utilizaremos o PHP com **Programação Orientada à Objetos**.

Os assuntos e exemplos estão divididos por `branches`, acessíveis pelo menu de branches no GitHub.

---

## Branch 02: Visibilidade e Encapsulamento

- Visibilidade de propriedades: <b>public</b> e <b>private</b>
- Encapsulamento
- Métodos <b>Getters</b> para leitura
- Métodos <b>Setters</b> para escrita

## Branch 01: Classes, Objetos, Propriedades, Métodos

- Classes e Objetos
- Propriedades e métodos
- Tipos de dados
- Uso do <b><code>$this</code></b> para acessar recursos de dentro da própria classe
